# 信息采集与解析文档

> 本项目已移除语音转写模块，当前支持 **文本** 与 **简历** 双通道。

## 1. 文本解析引擎

- **入口**：`POST /api/profile/parse`
- **限制**：50-800 字
- **实现**：`nlp_parser.py` + `keyword_dict.py`
- **输出**：知识 / 技能 / 协作三维 JSON + 1-10 评分

### 评分逻辑
- **知识分**：学历层级 + 专业匹配 + 理论关键词数量
- **技能分**：技术/工具/行业技能数 + 项目经验
- **协作分**：沟通档位 + 角色 + 风格 + 团队经历

## 2. 简历解析引擎

- **入口**：`POST /api/profile/resume`
- **格式**：PDF、DOCX（推荐）；DOC 返回 415
- **大小**：≤ 10MB
- **实现**：`resume_parser.py`（pypdf + python-docx）
- **流程**：文件校验 → 本地存储 → 抽文本 → NLP 管道

### 异常处理
| 情况 | 状态码 |
|------|--------|
| 格式不支持 | 415 |
| 文件过大 | 413 |
| 解析失败/乱码 | 422 |

## 3. 手动修正

用户可在前端编辑解析结果，`PUT /api/profile/{id}` 覆盖入库。

## 4. 性能目标

| 操作 | 目标 |
|------|------|
| 文本解析 | ≤ 2s |
| 简历解析 | ≤ 8s |
